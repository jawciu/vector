# Voice & copy

Rules for **all product copy and all design-system docs**: UI labels, buttons, empty
states, error messages, story descriptions, meta files, these pages. The tone
(`DESIGN.md`): clear, operator-focused, minimal chrome, action-led.

## The absolute rule: no em dashes

**Never use an em dash. Anywhere. Ever.** Rewrite with full stops, commas, colons or
parentheses.

| Wrong | Right |
| --- | --- |
| Tasks sync automatically — no setup needed. | Tasks sync automatically. No setup needed. |
| Invite the vendor — they get view access only. | Invite the vendor (they get view access only). |
| One thing left — kickoff. | One thing left: kickoff. |

## Sentence case, always

Headings, labels, buttons, menu options, pills: only the first word is capitalised,
plus proper nouns. Never Title Case. Source copy stays sentence case even when a CSS
treatment uppercases the rendered text (the small label, status pills).

| Wrong | Right |
| --- | --- |
| Add New Member | Add new member |
| Onboarding Overview | Onboarding overview |
| Focus Today | Focus today |

## British spelling

| Wrong | Right |
| --- | --- |
| Customize | Customise |
| Color | Colour |
| Prioritize | Prioritise |
| Behavior | Behaviour |

## Controls say exactly what happens

Active voice. A button's label is the action it performs, not a form ritual.

| Wrong | Right |
| --- | --- |
| Submit | Add member |
| OK (confirming a delete) | Delete task |
| Are you sure? | Delete task / Cancel |
| Click here to view report | View report |

## Clear, minimal, action-led

- Say the state plainly and stop. The reference register is the insight card empty
  states: "No active risks.", "Quiet week ahead."
- Short declarative sentences. Cut everything that does not inform.
- No decoration in status copy: status colours and status words are for state (see
  Foundations/Colours).
- Errors say what happened and what to do next, in that order.

| Wrong | Right |
| --- | --- |
| Oops! Something went wrong with your request. | Couldn't save the task. Try again. |
| There are currently no risks present at this time. | No active risks. |
