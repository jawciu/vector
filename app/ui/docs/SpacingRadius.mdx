# Spacing & radius

Both scales are Tailwind v4's defaults, used directly. The rung names in `DESIGN.md`
match the utilities, the utilities in use **are** the scale at runtime, and no
`--spacing-*` or `--radius-*` overrides are emitted.

## Spacing

The Tailwind default scale is in use everywhere; these are the values Vector leans on
most.

<Panel>
  <SpaceRow name="xs" px={4} />
  <SpaceRow name="sm" px={8} />
  <SpaceRow name="md" px={12} />
  <SpaceRow name="lg" px={16} />
  <SpaceRow name="xl" px={24} />
</Panel>

Where surfaces converge:

- **Padding**: 12px (sm), 16px (md), 20 to 24px (lg) on cards and panels.
- **Gaps**: 4px between menu items, 8 to 12px between cards, 24px between major sections
  in a grid.
- No formal grid system. The home page uses a 7-column CSS grid with explicit widths;
  the onboarding board is a flex row of fixed-width 240px kanban columns.

## Radius

Aligned to Tailwind v4's default radius scale (Caroline's ruling, 2026-08-09). The boxes
below render with the real utility classes, except the bespoke 20px card.

## Shape rules

| Use | Radius | Notes |
| --- | --- | --- |
| Avatars / initials circles | `rounded-full` | The **only** place `rounded-full` is correct |
| IconButton | `rounded-sm` (4px) | Always `rounded`, never `rounded-full` |
| Pills, status badges | `rounded-sm` / `rounded-md` | |
| Inputs, buttons | `rounded-lg` (8px) | |
| Cards, hero panels | 20px (bespoke) | InsightsPanel cards, PortfolioInsightsHero |
| Bulk action bar, modals | `rounded-xl` (12px) | Floating surfaces |

- **Don't ship `rounded-full` on a square element.** It is reserved for circles.
- Arbitrary values (`p-[13px]`, `rounded-[10px]`) are flagged by
  `vector/no-arbitrary-tailwind`: stay on the scale.
